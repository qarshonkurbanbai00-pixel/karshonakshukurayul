# АҚШҰҚЫР — ЦИФРЛЫҚ ШЕЖІРЕ

## Windows-та іске қосу
1. Python 3.9+ орнатыңыз (python.org, "Add to PATH" белгілеңіз).
2. Папканы ашып, CMD-де: `pip install -r requirements.txt` содан соң `python app.py`
   (немесе `run.bat` екі рет басыңыз).
3. Браузерде http://127.0.0.1:5000

## Интернетсіз жұмыс
Негізгі сайт интернетсіз жұмыс істейді. Карта (Leaflet) және 3D (Three.js) CDN-нен жүктеледі; интернет жоқ болса:
`static/vendor/leaflet.js`, `static/vendor/three.min.js` (r128) файлдарын қолмен салыңыз. Болмаса тізім/ескерту көрсетіледі.

## Мазмұнды қайда ауыстыру
- `data/history.json` — таймлайн және мектеп тарихы (фото, дереккөз)
- `data/places.json` — карта, экскурсия (**GPS координаталарын нақтылаңыз, қазіргілері шамамен**)
- `data/sources.json` — цифрлық архив, дереккөздер (файл/сілтеме)
- `data/interviews.json` — ауызша тарих (аудио/видео)
- `static/images/` — фотолар; `static/models/mosque.glb` — 3D модель
Белгісіз ақпарат «Дерек қажет» деп белгіленген; ешқандай тарихи факт ойдан шығарылмаған.
